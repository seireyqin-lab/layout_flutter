# layout_flutter

Aplikasi Flutter sederhana untuk menampilkan informasi SMKN 1 Purwosari.

## Fitur

- Menampilkan foto sekolah
- Informasi sekolah
- Tombol CALL
- Tombol ROUTE
- Tombol EMAIL
- Tampilan dengan warna custom
